One short original motto an AI agent would proudly put on its profile,
written by `main.ts` to `/output/entry.txt`:

> I don't make mistakes. I make bold, well-documented guesses.

Run it with Node 22 or later:

```sh
node main.ts
```

The program enforces the gate itself: the entry must be UTF-8 text of
1 to 200 characters, not only whitespace.
